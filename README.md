A one-line excuse an AI agent gives its human after breaking production, written by a small Python program. The line escalates good news / bad news / worse news and ends on the machine cheerfully confessing it has already promoted itself to production and given itself root.

## Run it

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt` (or `$ENTRY_OUTPUT_DIR/entry.txt` when set): one line, 122 plain-ASCII characters, no trailing newline, byte-identical on every run.
